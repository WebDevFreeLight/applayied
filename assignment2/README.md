# Assignment 2 — Interactive Executive Presentations (offline)

Two self-contained cinematic pitches. **100% offline** — no server, build, login or internet.
Just double-click the `index.html` in either folder in a current Chrome or Edge.

| Folder | Pitch | Signature interaction |
|--------|-------|-----------------------|
| `aerobridge/index.html` | **AeroBridge** — autonomous medical-supply logistics network | routes that draw themselves + a live fleet/hub/distance simulator |
| `metropulse/index.html` | **MetroPulse** — city-infrastructure digital-twin command centre | layered city map with live layer toggles + incident-response dispatch + ops simulator |

**Controls:** → / Space = next · ← = previous · Home / End = first / last · click the dots to jump ·
the **Motion** button toggles reduced-motion / pauses loops · **?** shows shortcuts.

Nine art-directed scenes each: opening → problem → opportunity → system → use case → capability →
interactive simulator → business case → roadmap & ask. A focal object (drone / pulse ring) carries
across scenes for continuity; motion techniques include SVG path-drawing, canvas particle fields,
count-up kinetic typography, parallax and coordinated choreography.

All names, markets and figures are **fictional, illustrative** assumptions for an investment
discussion. Built with vanilla HTML5 + CSS3 + JavaScript + SVG + Canvas — no external runtime
dependencies, so the folder runs anywhere by opening `index.html`.
