Architecture

A clean, layered full stack.

React + Vite + TS

SPA, i18n (EN/AR), ECharts, SignalR client, permission-aware UI.

.NET 8 Web API

Controllers + ActionPermissionFilter (RBAC), bilingual errors, SignalR hub.

Services (SqlSugar)

Business rules, transactions, optimistic concurrency, automation engine.

PostgreSQL

Relational model; all KPIs computed in SQL — no spreadsheet models.

Security

JWT auth, per-route permissions, forced-logout on disable, no silent deletes.

Realtime

SignalR pushes notifications, notices and live session tracking.

Scheduler

ZR.Tasks / Quartz job runs the business automation on a cron.

Web intelligence

A live executive dashboard — and an independent Power BI track.

Custom web dashboard

  • KPI cards: delivery · risk & governance · financial
  • 6 interactive visuals (budget vs actual vs EAC, trend, categories, risk matrix, health, overdue by owner)
  • 6 coordinated filters — dept, manager, project, status, cutoff, category
  • Drill-downs: finance KPI → transactions · delivery KPI → tasks/risks
  • Recomputes from SQL after a task update or posted expense

Power BI (separate deliverable)

  • Connected to the same PostgreSQL database — not CSVs
  • Star-schema model + calendar, single-direction filters
  • 4+ SQL queries · 6 DAX measures · management page
  • KPIs reconcile SQL = web = Power BI for the identical snapshot
Total · Overdue · Open high-risk · Approved budget · Actual spend — identical across all three layers
Automation & AI approach

It watches the portfolio — and helps you act.

Scheduled automation

  • Overdue-task escalation & budget-overrun alerts
  • Runs via ZR.Tasks/Quartz (cron) or on demand
  • Idempotent — unique dedupe key, safe retry (no double-send)
  • Delivers to Messages + realtime SignalR + persistent run log

AI, woven in

  • Multi-provider fallback chain (Groq → … 12 providers)
  • Assistant on every page — scoped to a project / all / compare
  • Dashboard insights · project summary · task-progress advice
  • AI autofill on create forms · AI-drafted alert bodies
